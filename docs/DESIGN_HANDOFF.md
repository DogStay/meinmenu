# Handoff: THE FIRST LINE | MILITARY RP — UI

## Overview
Полная замена визуальной части интерфейса кастомного DayZ-сервера «THE FIRST LINE | MILITARY RP»: главное меню, экраны загрузки, очередь на сервер, таймеры входа/респавна, система подсказок, модальные окна, tooltip и UI-kit. Цель — чтобы интерфейс читался как отдельная военная игра, а не как мод поверх стандартного DayZ.

Целевая реализация: DayZ Layout Editor — `.layout`, ImageWidget, TextWidget, ButtonWidget, текстуры EDDS/PAA, состояния через StatePAA.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML**. Это прототипы, показывающие задуманный вид и поведение, а не продакшн-код для копирования. Задача — воспроизвести эти экраны в целевой среде (DayZ .layout + EDDS/PAA-текстуры) её собственными средствами. HTML используется только как точный источник геометрии, цветов и типографики.

Открывать: `First Line Wireframes.dc.html` в Chrome (рядом должны лежать `support.js` и папка `assets/`). Страница листается сверху вниз; свежие итерации сверху. У каждого варианта есть id (8a, 7b, 5a…), по нему удобно ссылаться.

## Fidelity
Смешанная, по разделам:
- **High-fidelity** — turn 5–8 (главное меню, загрузка, очередь, таймеры, диалоги, UI-kit, hint card, asset sheet). Финальные цвета, типографика, отступы, состояния. Воспроизводить попиксельно.
- **Low-fidelity** — turn 1–4 (каркасы всех 14 экранов ТЗ, компоновки, матрицы состояний, тайминги). Это структурная и передаточная документация: размеры, отступы, названия ассетов, тайминги анимаций.

## Base geometry
- Базовое разрешение **1920×1080**; адаптация под 2560×1440, 3440×1440, 3840×2160
- Safe-zone: **88px** по горизонтали, **48px** по вертикали — критические элементы не ближе
- Сетка **8px**, скруглений нет (radius 0)
- Хай-фай карточки в HTML отрисованы в масштабе **1280×720 = 0.667× от 1920×1080** — все px в файле умножать на 1.5 для реальных размеров

## Interactions & Behavior
| Переход | Длительность | Кривая |
|---|---|---|
| NORMAL → HOVER | 180 ms | ease-out |
| HOVER → NORMAL | 120 ms | linear |
| HOVER → PRESSED | 80 ms | linear |
| PRESSED → HOVER | 100 ms | linear |
| Tooltip | задержка 400 ms, fade 120 ms | linear |
| Смена подсказки | fade out 120 → swap → fade in 160 | ease-out |
| Появление меню | логотип 0–240, лента 80–340, статус-бар 140–380 | ease-out |
| Progress fill | lerp 250 ms, без отката | ease-out |
| Фон | zoom 8% за 40 s, ping-pong | linear |

Никаких bounce/elastic. Focus (геймпад/стрелки) — рамка olive 2px с отступом 4px, отдельный виджет поверх кнопки.

## Состояния кнопок
Габариты **не меняются ни в одном состоянии** — подменяется только текстура.
```
NORMAL    фон #141819 · граница #23282A · текст #D6D7D2
HOVER     фон #1C2122 · граница #38403A · марка 4px #7C8563 · текст #ECEDE9
PRESSED   фон #0F1213 · марка #5E6749 · текст #C2C4BE · сдвиг +2px
DISABLED  фон #121516 · граница 40% · текст #5A5E5B · без марки
ACTIVE    как NORMAL + марка olive (без подсветки фона) — только secondary
```
PRIMARY отличается заливкой (olive 12–20%), границей #7C8563 и высотой, но не цветом текста. DANGER не заливается красным — только граница и марка.
